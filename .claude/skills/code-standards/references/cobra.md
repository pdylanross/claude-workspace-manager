# cobra v1.10.2

`github.com/spf13/cobra`. Flags are `github.com/spf13/pflag` (POSIX/GNU-style), aliased `flag` in
cobra's own signatures. Source: full upstream docs in module cache (`site/content/*.md`, `README.md`)
+ `go doc -all github.com/spf13/cobra`. Version-exact.

## Core model

A `*cobra.Command` is a node in a tree. `Execute()` on the root parses `os.Args[1:]`, walks to the
target command, parses flags, validates args, runs lifecycle hooks. Commands are values you
construct; cobra has no constructors and no registry.

A command with no `Run`/`RunE` is not runnable — it prints help and requires a subcommand.

## Command struct — fields that matter

### Identity / help
| Field | Type | Notes |
|---|---|---|
| `Use` | `string` | First word is the command name. Rest is the usage line. Syntax: `[ ]` optional, `...` repeatable, `\|` mutually exclusive, `{ }` required-mutually-exclusive. e.g. `add [-F file \| -D dir]... profile` |
| `Aliases` | `[]string` | Alternate names, accepted at parse time. |
| `SuggestFor` | `[]string` | Names for which this command is *suggested* but not accepted. |
| `Short` | `string` | One line, shown in parent's command list. |
| `Long` | `string` | Shown in `help <cmd>`. |
| `Example` | `string` | Shown in help under Examples. |
| `Version` | `string` | Set on root → cobra auto-adds `--version`/`-v`. Template via `SetVersionTemplate`. |
| `Deprecated` | `string` | Non-empty → prints this string when used. |
| `Hidden` | `bool` | Omitted from help, still executable. |
| `GroupID` | `string` | Group in parent's help. Parent must `AddGroup(&cobra.Group{ID, Title})` first. |
| `Annotations` | `map[string]string` | Free-form. `cobra.CommandDisplayNameAnnotation` fixes help text for plugin-style binaries (`kubectl-foo` displayed as `kubectl foo`). |

### Behaviour
| Field | Type | Notes |
|---|---|---|
| `Args` | `PositionalArgs` | Positional validation. `nil` ⇒ `ArbitraryArgs`. |
| `ValidArgs` | `[]Completion` | Static completions for positional args. Also the allowed set for `OnlyValidArgs`. |
| `ValidArgsFunction` | `CompletionFunc` | Dynamic version. Mutually exclusive with `ValidArgs`. |
| `ArgAliases` | `[]string` | Accepted but not suggested. |
| `SilenceUsage` | `bool` | **Set true.** Otherwise every runtime error dumps the full help text. |
| `SilenceErrors` | `bool` | Suppresses cobra printing the error. Leave false unless printing it yourself — otherwise errors vanish. |
| `TraverseChildren` | `bool` | Parse local flags on each parent while walking to the target. Off by default (parents' local flags ignored). |
| `DisableFlagParsing` | `bool` | All flags passed through as args. For wrapper/passthrough commands. |
| `DisableFlagsInUseLine` | `bool` | Suppress the auto-appended `[flags]`. |
| `DisableSuggestions` | `bool` | Turn off "Did you mean…" |
| `SuggestionsMinimumDistance` | `int` | Levenshtein threshold, default 2. |
| `DisableAutoGenTag` | `bool` | Removes "Auto generated by spf13/cobra" from docgen output. |
| `FParseErrWhitelist` | `FParseErrWhitelist` | `{UnknownFlags: true}` to tolerate unknown flags. |
| `CompletionOptions` | `CompletionOptions` | See Completions. Set on **root** only. |

### Lifecycle hooks

Execution order:
```
PersistentPreRun(E) → PreRun(E) → Run(E) → PostRun(E) → PersistentPostRun(E)
```
Signatures: `func(cmd *Command, args []string)`, `E` variants return `error`.

- `Persistent*` are inherited by children **that do not declare their own**.
- By default only the **first** persistent hook found walking up the tree runs. Set the package var
  `cobra.EnableTraverseRunHooks = true` to run all ancestors' persistent hooks.
- `*PreRun`/`*PostRun` only fire if the command has a `Run`/`RunE`.
- If both `X` and `XE` are set, the `E` variant wins.

## Args validators

`type PositionalArgs func(cmd *Command, args []string) error`

| Validator | Behaviour |
|---|---|
| `NoArgs` | Error on any positional arg. |
| `ArbitraryArgs` | Never errors. The default when `Args` is nil. |
| `MinimumNArgs(n)` | Error if `< n`. |
| `MaximumNArgs(n)` | Error if `> n`. |
| `ExactArgs(n)` | Error if `!= n`. |
| `RangeArgs(min, max)` | Error if outside range. |
| `OnlyValidArgs` | Error on any arg not in `ValidArgs`. |
| `MatchAll(a, b, ...)` | Compose. e.g. `MatchAll(ExactArgs(1), OnlyValidArgs)`. |

Custom validators are any func of that signature; compose by calling a builtin first:
```go
Args: func(cmd *cobra.Command, args []string) error {
    if err := cobra.MinimumNArgs(1)(cmd, args); err != nil { return err }
    if !isValid(args[0]) { return fmt.Errorf("invalid: %s", args[0]) }
    return nil
},
```

## Flags

pflag under the hood. Every `Xxx` has `XxxP` (adds shorthand) and `XxxVar`/`XxxVarP` (binds to a
pointer) forms.

| Accessor | Scope |
|---|---|
| `cmd.Flags()` | Everything applying to this command: its own local + persistent inherited from parents. Use this to **read**. |
| `cmd.PersistentFlags()` | Declare a flag inherited by this command and all descendants. |
| `cmd.LocalFlags()` | Local to this command only. |
| `cmd.InheritedFlags()` | From parents only. |
| `cmd.Flag(name)` | Climb the tree for a single `*pflag.Flag`. |

Declaring:
```go
cmd.Flags().BoolVarP(&short, "short", "s", false, "print only the version string")
cmd.PersistentFlags().StringVar(&cfg, "config", "", "config file")
```

Common types: `Bool`, `String`, `Int`/`Int64`, `Float64`, `Duration`, `StringSlice` (comma-separated
**or** repeated), `StringArray` (repeated only, no comma splitting), `Count` (repeat to increment:
`-vvv` → 3), `IP`, `StringToString`.

`StringSlice` vs `StringArray`: `StringSlice` splits on commas — wrong if values can contain commas.
Default to `StringArray` unless comma-splitting is desired.

### Constraints

| Call | Effect |
|---|---|
| `cmd.MarkFlagRequired(name)` | Error if absent. |
| `cmd.MarkPersistentFlagRequired(name)` | Same, for persistent. |
| `cmd.MarkFlagsRequiredTogether(a, b, ...)` | All or none. |
| `cmd.MarkFlagsMutuallyExclusive(a, b, ...)` | At most one. |
| `cmd.MarkFlagsOneRequired(a, b, ...)` | At least one. Combine with mutually-exclusive for exactly-one. |

All return `error` except the three `MarkFlags*` group funcs (which panic on unknown flag names).
Group constraints are enforced **only on commands where every named flag is defined** — a group
spanning a flag the command doesn't have is silently skipped.

## Errors

- `RunE` returning an error → cobra prints `Error: <err>` to stderr and `Execute()` returns it.
- With `SilenceUsage: false` (default) it also dumps usage. Set it true.
- Error prefix customizable: `cmd.SetErrPrefix(s)`.
- `Execute()` returns the error; the caller decides the exit code. Do not `os.Exit` inside `RunE`.
- `cobra.CheckErr(msg)` prints and `os.Exit(1)`. **Do not use** — it makes code untestable.

## I/O

| Method | Returns |
|---|---|
| `cmd.OutOrStdout()` | `io.Writer` — the set output, else `os.Stdout`. |
| `cmd.ErrOrStderr()` | `io.Writer` — the set error output, else `os.Stderr`. |
| `cmd.InOrStdin()` | `io.Reader`. |
| `cmd.SetOut(w)` / `SetErr(w)` / `SetIn(r)` | Override; inherited by children. |
| `cmd.SetOutput(w)` | Deprecated — sets both out and err. Use `SetOut`+`SetErr`. |

`cmd.Print*`/`PrintErr*` write to those writers. **Always** route output through these, never
`fmt.Println` — it is the only thing that makes commands testable.

## Context

- `cmd.ExecuteContext(ctx)` sets the context on the tree; retrieve via `cmd.Context()` inside hooks,
  `RunE`, and completion functions.
- `cmd.Context()` returns `nil` before `Execute`; after `Execute`/`ExecuteC` a nil context is
  replaced with `context.Background()`.
- `cmd.SetContext(ctx)` sets it directly.

## Help / usage / version

| Call | Effect |
|---|---|
| `cmd.SetHelpCommand(c)` | Replace the auto `help` command. |
| `cmd.SetHelpFunc(f)` | `func(*Command, []string)`. Inherited by children. |
| `cmd.SetHelpTemplate(s)` / `SetUsageTemplate(s)` / `SetVersionTemplate(s)` | `text/template` strings. |
| `cmd.SetUsageFunc(f)` | `func(*Command) error`. |
| `cmd.AddGroup(&cobra.Group{ID: "x", Title: "X commands:"})` | Group subcommands; set `GroupID` on children. |
| `cmd.SetHelpCommandGroupID(id)` / `SetCompletionCommandGroupID(id)` | Group the generated commands. |

Templates are evaluated with `text/template` and grow the binary. Prefer defaults.

## Completions

Cobra ships a working `completion` command automatically (bash/zsh/fish/powershell), hidden when
there are no other subcommands. It uses bash completion **V2**.

Root-only config:
```go
rootCmd.CompletionOptions.DisableDefaultCmd = true   // no completion command
rootCmd.CompletionOptions.HiddenDefaultCmd  = true   // present but hidden
rootCmd.CompletionOptions.DisableNoDescFlag = true   // no --no-descriptions flag
rootCmd.CompletionOptions.DisableDescriptions = true // no descriptions at all
rootCmd.CompletionOptions.SetDefaultShellCompDirective(cobra.ShellCompDirectiveNoFileComp)
```

Types:
```go
type Completion = string
type CompletionFunc = func(cmd *Command, args []string, toComplete string) ([]Completion, ShellCompDirective)
```

Dynamic completion — set `ValidArgsFunction` on the command, or register per-flag:
```go
cmd.RegisterFlagCompletionFunc("output", func(cmd *cobra.Command, args []string, toComplete string) ([]cobra.Completion, cobra.ShellCompDirective) {
    return []cobra.Completion{"json", "table", "yaml"}, cobra.ShellCompDirectiveNoFileComp
})
```
Cobra parses all flags/args before calling it — do not re-parse.

### ShellCompDirective (bit field, combine with `|`)
| Directive | Meaning |
|---|---|
| `ShellCompDirectiveDefault` | Shell's default behaviour (**includes filename completion**). The implicit default when nothing is registered. |
| `ShellCompDirectiveError` | Error occurred; ignore completions. |
| `ShellCompDirectiveNoSpace` | No trailing space after a single completion. |
| `ShellCompDirectiveNoFileComp` | Suppress file completion. |
| `ShellCompDirectiveFilterFileExt` | Returned values are file extensions to filter on. |
| `ShellCompDirectiveFilterDirs` | Only directories. Returning one value = search within that dir. |
| `ShellCompDirectiveKeepOrder` | Preserve the returned order. |

Helpers: `cobra.NoFileCompletions` (a ready-made `CompletionFunc`), `cobra.FixedCompletions(list, directive)`,
`cobra.CompletionWithDesc("value", "description")` (description after a `\t`).

Flag value filtering shortcuts: `cmd.MarkFlagFilename(name, "yaml", "json")`, `cmd.MarkFlagDirname(name)`.

### Debugging completions
```sh
cwm __complete <cmd> ""        # empty string arg is REQUIRED for an empty noun
```
Never print to stdout from completion code — it is parsed as completion values. Use
`cobra.CompDebug`/`CompDebugln`/`CompError`/`CompErrorln` (honour `BASH_COMP_DEBUG_FILE`).

## Active Help

Hints surfaced through the completion system. Bash V2 (bash ≥4.4) and zsh only.
```go
comps = cobra.AppendActiveHelp(comps, "You must choose a name")
```
User config read via `cobra.GetActiveHelpConfig(cmd)`, backed by env `<PROGRAM>_ACTIVE_HELP`
(falling back to `COBRA_ACTIVE_HELP`); `"0"` disables all active help globally. `<PROGRAM>` is the
root command name uppercased with non-alphanumerics → `_`.

## Doc generation

`github.com/spf13/cobra/doc` — separate import. `doc.GenMarkdownTree(cmd, dir)`, plus man / ReST /
YAML variants. Set `cmd.DisableAutoGenTag = true` to drop the generated-by footer. Call
`cmd.InitDefaultCompletionCmd()` first if the completion command should be documented.
**Not used in this project.**

## Package-level knobs

| Var | Default | Effect |
|---|---|---|
| `EnableCommandSorting` | `true` | Alphabetical subcommand ordering. |
| `EnablePrefixMatching` | `false` | Accept unambiguous command prefixes. Risky. |
| `EnableCaseInsensitive` | `false` | Case-insensitive command names. |
| `EnableTraverseRunHooks` | `false` | Run all ancestors' persistent hooks, not just the nearest. |
| `MousetrapHelpText` | non-empty | Windows explorer.exe splash. Set `""` to disable. |

Also `cobra.OnInitialize(fns...)` / `cobra.OnFinalize(fns...)` — run on every `Execute`. Both mutate
global state; **avoid**, wire explicitly instead.

## Gotchas

1. **`SilenceUsage: false` (the default) dumps the entire help text on every runtime error.** Set it
   `true` on the root. Do NOT also set `SilenceErrors` unless printing the error yourself, or errors
   disappear silently.
2. **`Execute()` returns the error AND cobra has already printed it.** Printing it again in `main`
   double-reports. Just set the exit code.
3. **`ValidArgs` and `ValidArgsFunction` are mutually exclusive.** Setting both is a silent bug.
4. **`ValidArgs` is completion metadata, not validation.** It only rejects input when `Args` includes
   `OnlyValidArgs`.
5. **Default completion behaviour is filename completion.** A leaf command with no registered
   completion function offers files. Register `cobra.NoFileCompletions` where that is wrong.
6. **Parents' local flags are ignored** unless `TraverseChildren` is set. Use `PersistentFlags()` for
   anything meant to be inherited.
7. **Only the nearest persistent hook runs** by default — a root `PersistentPostRun` does not fire
   for a child that declares its own. Needs `EnableTraverseRunHooks`.
8. **`*PreRun`/`*PostRun` never fire on a command with no `Run`/`RunE`.**
9. **Flag group constraints are skipped** on commands that don't define every flag in the group.
10. **`StringSlice` splits on commas**; `StringArray` does not. Wrong choice silently mangles values
    containing commas.
11. **Reusing a `*cobra.Command` across `Execute()` calls leaks state** — flag values persist.
    Build a fresh tree per execution. This is why commands are built by constructors here, and what
    makes the tests correct.
12. **`--version` only appears if `Version` is non-empty on the root**, and only if no `version` flag
    is already defined.
13. **`MarkFlagsMutuallyExclusive` and friends panic** on unknown flag names; the `MarkFlag*`
    singular forms return `error`.
14. **`cobra.CheckErr` calls `os.Exit(1)`** — unusable in tests. Never use it.

## Project conventions

This repo rejects most of cobra's own documented idioms because of the linter. Upstream examples use
package-level `var rootCmd` + `init()`; both are forbidden here (`gochecknoglobals`,
`gochecknoinits`, outside `cmd/`).

Required shape — see `internal/cli/`:

```go
// internal/cli/version.go
func newVersionCmd(info version.Info) *cobra.Command {
    var short bool

    cmd := &cobra.Command{
        Use:   "version",
        Short: "Print the cwm version",
        Args:  cobra.NoArgs,
        RunE: func(cmd *cobra.Command, _ []string) error {
            text := info.String()
            if short {
                text = info.Short() + "\n"
            }
            _, err := io.WriteString(cmd.OutOrStdout(), text)
            return err
        },
    }

    cmd.Flags().BoolVarP(&short, "short", "s", false, "print only the version string")

    return cmd
}
```

Rules:
- One `newXxxCmd(deps...) *cobra.Command` constructor per command, one file per command, in
  `internal/cli`. Registered via `AddCommand` in `newRootCmd`.
- Dependencies are constructor parameters. No globals, no `init()`, no `OnInitialize`.
- Flag target vars are locals in the constructor, captured by the `RunE` closure.
- `RunE`, never `Run` — errors propagate to `Execute()`.
- Always set `Args` explicitly. `cobra.NoArgs` for commands taking none; omitting it means
  `ArbitraryArgs`, which silently accepts garbage.
- Output via `cmd.OutOrStdout()`. Never `fmt.Println`.
- `SilenceUsage: true` on the root (`internal/cli/root.go`).
- `cmd/cwm/main.go` stays thin: build `version.Info` from the ldflag vars, call `cli.Execute(info)`,
  `os.Exit(1)` on error. No printing.
- `RunE` returns must be wrapped (`wrapcheck`): `fmt.Errorf("write version output: %w", err)`, never a
  bare `return err` from a cobra or stdlib call.
- `exhaustruct_v5` would demand all 31 `cobra.Command` fields on every literal. It is filtered for
  `cobra.Command` by a `text:` rule in `.golangci.yml`, so partial `&cobra.Command{...}` literals are
  correct and expected here. Do not add `//exhaustruct:ignore` to command constructors.

## Testing

Build the tree, redirect output, set args, execute:

```go
var out bytes.Buffer

cmd := cli.NewRootCmd(info)   // via export_test.go — see SKILL.md §3.3
cmd.SetOut(&out)
cmd.SetErr(&out)
cmd.SetArgs([]string{"version", "--short"})

if err := cmd.Execute(); err != nil { t.Fatalf("Execute() error = %v", err) }
```

- Build a **fresh** command tree in every subtest — flag state persists otherwise, and this is what
  makes `t.Parallel()` safe.
- `SetArgs` replaces `os.Args[1:]`; without it the test picks up the `go test` flags.
- Set both `SetOut` and `SetErr`; cobra writes errors and usage to the err writer.
- Assert on the buffer contents and the returned error. Test rejected input too (bad flag,
  unexpected positional arg) — that is what proves `Args` and flag wiring are right.

Reference implementation: `internal/cli/root_test.go`, `internal/cli/export_test.go`.
